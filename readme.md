# 🚀 FISSA — Compare. Vote. Partage.

FISSA est une plateforme web et mobile de comparaison visuelle et vidéo interactive.

## 🌟 Fonctionnalités
- ⚡ **Duels A/B** : Vote en temps réel entre deux créations.
- 📰 **Fil d'actualité & Stories** : Publication de contenus courts (photos/vidéos).
- 💬 **Espace Communauté** : Commentaires et partage.
- 📱 **Multiplateforme** : PWA installable sur Android, iOS et macOS via Capacitor.

## 🛠️ Stack Technique
- **Frontend** : HTML5, CSS3, JavaScript (ES6 Modules)
- **Backend & Auth** : Firebase (Firestore, Auth)
- **Mobile Engine** : Capacitor JS
